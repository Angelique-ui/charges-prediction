# charges-prediction
Projet de prédiction des charges médicales (formation Jedha)

Projet réalisé dans le cadre de ma formation chez Jedha.  
L’objectif est de prédire les charges médicales (assurance santé) selon plusieurs variables comme l’IMC, le statut fumeur, l’âge, etc.

Outils utilisés :
- Python, Pandas, Scikit-learn, Seaborn, Matplotlib
- Power BI pour la visualisation

Objectif :
- Comprendre les facteurs qui influencent le coût
- Créer un modèle de prédiction simple et interprétable
